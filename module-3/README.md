# Module 3 – Combinational and Sequential Optimizations

## Overview
This module explains combinational and sequential optimization techniques using Yosys and Sky130 standard cells.

---

## 1. Constant Propagation

Constant propagation simplifies a logic circuit by replacing constant inputs (0 or 1), reducing unnecessary logic and improving circuit efficiency.

## 2. Sequential Logic Optimizations

Sequential logic optimization improves sequential circuits using techniques like Sequential Constant Propagation, State Optimization, Retiming, and Sequential Logic Cloning.
